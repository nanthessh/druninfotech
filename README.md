# DRUN — Official Modern Startup Website

Welcome to the official **DRUN** (Design • Develop • Deliver • Scale) website, engineered with **Angular 21**, **Tailwind CSS v4**, and deep **WhatsApp** & **Gmail** connectivity.

---

## 🌟 What Was Built

### 1. 🎨 Brand Identity & Logo
- Uses your official uploaded DRUN logo (`/assets/drun-logo.jpg` and `/assets/drun-logo.svg`) with styled navy and slate blue brand aesthetics.
- Seamlessly styled in the navbar, hero section, footer, and favicon.

### 2. 🚀 Dedicated Digital Marketing Wing (`#digital-marketing`)
- **SEO & Google Search Dominance**: Core Web Vitals, local search, schema markup.
- **Performance Advertising (Meta & Google PPC)**: High-converting video ads, pixel tracking, ROAS optimization.
- **WhatsApp Funnels**: Click-to-WhatsApp ad campaigns with conversational qualification.
- **Social Media & Brand Scaling**: Content creation, viral reels, and authority building.
- **Conversion Rate Optimization (CRO)**: Frictionless mobile flows and landing pages.
- **Interactive Growth & Ad ROI Estimator**: Slider allowing clients to test their monthly budget (₹20,000 to ₹5,00,000+) to see estimated impressions, qualified leads, and target ROAS.
- Direct buttons to dispatch the marketing plan to WhatsApp or Gmail.

### 3. 💻 Software Engineering Capabilities (`#services`)
- **Web Applications**: Single-page apps with Angular 21, TypeScript, and modern UI.
- **Business Software & ERP**: Custom internal dashboards, CRM, and automated invoicing.
- **APIs & Cloud Integrations**: Scalable REST APIs, payment gateways (Razorpay, Stripe), and webhooks.
- **Database Architecture**: PostgreSQL / SQL Server schema modeling and reliability.
- **UI/UX & Design Systems**: Human-centric Figma interfaces and component libraries.

### 4. 💰 Instant Project Scoper & Calculator (`#calculator`)
- Interactive project estimator where clients can select:
  - Project Type (Web App, Marketing, ERP, Turnkey Suite)
  - Features (Auth, Payments, WhatsApp Bot, SEO, Ads, Analytics)
  - Timeline Pace
- Outputs an instant scope estimate in INR (₹) and USD ($) with one-click buttons to send the scope to DRUN via WhatsApp or Gmail.

### 5. 💬 Advanced WhatsApp & Gmail Connectivity
- **WhatsApp Direct Connect**:
  - Direct founder line: `+91 93602 66792`
  - Floating WhatsApp chat launcher at the bottom-right corner with a live conversation drawer and quick starter chips.
  - Contextual pre-filled WhatsApp message generators across every section.
- **Gmail Direct Connect**:
  - One-click "Compose in Gmail" button that opens `mail.google.com` with formatted subject and body.
  - One-click "Copy Email Address" with toast feedback (`druntech.official@gmail.com`).
  - Interactive Contact Form with direct options to submit online or dispatch to WhatsApp/Gmail.
- **Headquarters**: Coimbatore, Tamil Nadu, India.

## 🛠️ How to Run Locally

```bash
# 1. Start the development server
npm start

# Or to preview the compiled production build:
node serve.js
```
Then open `http://localhost:4200` in your browser.

---

## 🚀 How to Deploy to Vercel

The project is already pre-configured with `vercel.json`!

```bash
# Deploy instantly with the Vercel CLI:
npx vercel --prod
```
Or simply push this folder to your GitHub repository and link it to your Vercel project (`d-run-wzjl.vercel.app`).
- **Build Command**: `npm run build`
- **Output Directory**: `dist/drun/browser`
